# AgentUsageV2

Windows 작업표시줄 옆에 두는 AI 구독 사용량 위젯입니다. ChatGPT · Gemini · Claude를 각각의 브랜드 색상으로 3줄에 표시하고, 클릭하면 세션·주간 사용량을 펼쳐 보여줍니다. 위젯은 항상 위에 표시되며 상단 제목을 드래그해 옮길 수 있습니다. 작업표시줄에 앱 아이콘이 표시되고, 설치된 앱을 작업표시줄에 고정할 수 있습니다. 숨겨도 트레이 아이콘이나 고정된 작업표시줄 아이콘으로 다시 열 수 있습니다.

## 현재 구현 범위

| 서비스 | 3줄 위젯 | 자동 사용량 수집 |
| --- | --- | --- |
| ChatGPT | 초록색 | 이 버전에서 미지원 |
| Gemini | 파랑·보라색 | 이 버전에서 미지원 |
| Claude | 테라코타색 | 세션 쿠키로 직접 조회 또는 사용량 화면 확장 연동 (실험적) |

**잔여 구독 한도(%)를 표시합니다.** 서비스가 공개하지 않는 정확한 토큰 수나 한도를 추정하지 않습니다. ChatGPT의 구독 사용량을 Codex/API 사용량으로 대체하지 않으며 Gemini에 일률적인 5시간 한도를 적용하지 않습니다. 데이터가 없으면 `미지원`, `연결 대기`, `수치 없음`으로 표시합니다.

Claude는 현재 세션(5시간), 주간 전체 모델, 화면에 있을 경우 Sonnet·Opus 주간 한도를 표시합니다. 읽지 못한 항목은 생성하지 않습니다. 마지막 수신 후 15분이 지나면 오래된 정보라는 경고를 표시합니다. 초기화 시점은 페이지의 문구를 그대로 표시하며 별도로 계산하지 않습니다.

## Windows에서 실행

Windows 10/11이 대상입니다. 소스로 실행할 때는 Node.js 24 LTS가 필요하고, 브라우저 확장 방식에는 Chrome 또는 Edge가 필요합니다.

실행용 `AgentUsageV2-0.2.0-win.zip`을 받았다면 Node.js나 npm은 필요 없습니다. ZIP을 문서 폴더 등 유지할 위치에 **모두 압축 해제**하고 `AgentUsageV2.exe`를 실행하세요. ZIP 안에서 바로 실행하지 마세요. 고정 후에는 실행 파일 폴더를 이동하지 않는 것이 좋습니다.

아래는 소스로 실행하는 개발용 절차입니다.

먼저 프로젝트 파일을 Windows PC로 가져와야 합니다. 클라우드에서 만든 파일은 PC나 GitHub에 자동으로 복사되지 않습니다. 소스 ZIP을 다운로드 폴더에 저장했다면 PowerShell에서 다음을 실행하세요. 압축 안에는 `AgentUsageV2` 폴더가 포함되어 있습니다.

```powershell
Expand-Archive -LiteralPath "$HOME\Downloads\AgentUsageV2-source.zip" -DestinationPath "$HOME\Documents"
Set-Location "$HOME\Documents\AgentUsageV2"
Get-Item .\package.json, .\package-lock.json
npm ci
npm run dev
```

프로젝트를 다른 위치에 저장했다면 그 위치의 `AgentUsageV2` 폴더로 이동하세요. 이후의 모든 `npm` 명령은 `package.json`과 `package-lock.json`이 있는 폴더에서 실행해야 합니다. 사용자 홈 폴더(`C:\Users\사용자명`)에서 `npm ci`를 실행하면 잠금 파일을 찾지 못하는 `EUSAGE` 오류가 납니다. 잠금 파일이 포함된 프로젝트를 받아야 하며, 홈 폴더에 새 npm 프로젝트를 만들 필요는 없습니다.

개발 서버 없이 실행하려면:

```powershell
npm run build
npm start
```

Windows 로그인 시 시작하려면 상세 화면 아래의 `Windows 시작 시 실행`을 켜세요. 이 설정은 빌드된 Windows 앱에서만 활성화됩니다. 트레이 메뉴에서 위젯 표시, 주간 사용량 보기, 종료를 선택할 수 있습니다.

## 작업표시줄에 고정

1. Windows 실행용 ZIP을 모두 압축 해제하고 `AgentUsageV2.exe`를 실행합니다. 또는 프로젝트 폴더에서 `npm run dist:win`으로 만든 `release` 폴더의 설치 파일을 설치합니다.
2. 설치 버전이면 시작 메뉴에서 **AgentUsageV2**를 실행합니다.
3. 위젯과 함께 작업표시줄의 앱 아이콘이 표시되는지 확인합니다.
4. 작업표시줄의 **AgentUsageV2 아이콘을 우클릭 → 작업 표시줄에 고정**을 선택합니다. 시작 메뉴의 앱에서 **더 보기 → 작업 표시줄에 고정**을 선택해도 됩니다.

Windows의 고정 선택은 사용자가 한 번 직접 해야 합니다. 빌드된 앱의 실행 경로·이름·아이콘을 등록했으므로, 이후 고정 아이콘으로 앱을 다시 실행하거나 트레이에 숨긴 위젯을 열 수 있습니다. `npm run dev`로 실행한 개발용 Electron 대신 실행용 ZIP의 앱 또는 설치된 AgentUsageV2를 고정하세요. 사용량 3줄은 작업표시줄 옆 위젯에 표시됩니다.

## Claude 자동 연동

### 사이트를 열어두지 않는 세션 조회

1. Windows 앱에서 상세 화면 → **연결 설정 → 사이트를 열지 않고 확인**을 엽니다.
2. 최초 한 번 Claude에 로그인한 브라우저에서 F12 → Application(애플리케이션) → Cookies → `https://claude.ai`의 `sessionKey` 값을 복사합니다. 다른 쿠키나 전체 Cookie 헤더는 필요하지 않습니다.
3. **앱의 비밀번호 입력란에만** 값을 붙여 넣고 **저장하고 자동 조회**를 누릅니다. 채팅에 쿠키를 보내지 마세요.
4. 여러 조직에 소속되어 있으면 앱에서 조회할 조직을 선택합니다.
5. 최초 조회가 성공하면 브라우저와 사용량 탭을 닫아도 됩니다. 앱이 켜져 있는 동안 5분마다 갱신하고, 재실행하면 저장된 세션으로 다시 조회합니다.

쿠키는 Electron `safeStorage`를 통해 Windows 계정의 DPAPI로 암호화해 `%APPDATA%/agentusagev2/claude-session.enc`에 저장합니다. 암호화 저장을 사용할 수 없으면 평문으로 저장하지 않습니다. 쿠키는 `https://claude.ai`에만 보내며 리다이렉트를 따라가지 않습니다. 쿠키를 바꾸거나 삭제할 때 이전 계정의 수치를 지우고 진행 중인 조회 결과를 버립니다. 앱 상태·사용량 파일·로그에는 쿠키를 넣지 않습니다.

쿠키는 계정 로그인 권한을 가진 값입니다. 만료·로그아웃·접근 거부 시 앱에 오류가 표시되고 자동 재시도를 멈춥니다. 필요하면 새 쿠키를 등록하거나 **저장된 세션 삭제**로 확장 방식으로 전환하세요. 요청 제한(429)과 일시적 오류는 대기 후 재시도합니다.

이 방식은 Claude의 **비공식 웹 사용량 엔드포인트**를 사용합니다. 서비스 변경, Cloudflare 확인, 계정별 제공 범위에 따라 실패할 수 있습니다. 실제 계정·Windows DPAPI는 이 Linux 환경에서 검증하지 않았으며, 테스트용 응답과 암호화 인터페이스로 검증했습니다. 요청 경로와 응답 필드는 공개 참고 자료인 [CodexBar의 Claude 웹 조회 설명](https://github.com/steipete/CodexBar/blob/489aad74fbd55a22db570c025b6d57aac654cd5a/Sources/CodexBarCore/Providers/Claude/ClaudeWeb/ClaudeWebAPIFetcher.swift)을 확인했습니다. 직접 조회가 설정되어 있으면 확장 데이터로 덮어쓰지 않습니다.

ChatGPT·Gemini는 쿠키가 있더라도 이 버전에서 구독 잔여 한도를 직접 읽는 기능을 구현하지 않았습니다.

### 대체 방식: 브라우저 확장

직접 조회를 사용 중이면 먼저 앱에서 **저장된 세션 삭제**를 누르세요.

1. Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`에서 개발자 모드를 켭니다.
2. **압축해제된 확장 프로그램 로드**로 이 프로젝트의 `extension` 폴더를 선택합니다. 빌드 산출물을 받았다면 확장 ZIP을 먼저 압축 해제합니다.
3. 데스크톱 앱에서 상세 화면 → **연결 설정 → 연결 키 복사**를 누릅니다.
4. 브라우저의 확장 아이콘을 누르고 연결 키를 붙여 넣어 **앱 연결**을 누릅니다.
5. 같은 브라우저에서 `https://claude.ai/settings/usage`에 로그인하고 사용량 페이지를 엽니다. 이미 열려 있었다면 한 번 새로고침하세요.
6. 확장에서 **지금 동기화**를 누릅니다. 이후 연결된 확장은 열려 있는 사용량 페이지 하나를 1분마다 새로고침하며, 렌더링된 수치를 앱으로 보냅니다. 해당 탭을 닫으면 갱신이 멈춥니다. 채팅 탭은 새로고침하지 않습니다.

영어·한국어의 알려진 사용량 문구만 읽습니다. Claude 화면 구조·문구 변경, 로딩 지연, 사용량을 제공하지 않는 요금제, 브라우저의 백그라운드 탭 절전 기능에 따라 동기화가 실패하거나 지연될 수 있습니다. 확장 팝업에 마지막 오류를 표시합니다. **실제 로그인 계정에서의 연동은 아직 검증하지 않았습니다.** 현재 검증은 명시적인 테스트용 페이지와 데이터로 진행합니다.

브라우저 확장 자체는 쿠키·비밀번호·세션 토큰·대화 내용을 수집하거나 앱으로 전송하지 않습니다. 확장은 사용량 페이지의 보이는 텍스트를 로컬에서 분석하고 정규화된 한도 수치와 초기화 문구만 보냅니다. 확장은 서비스 API를 호출하지 않습니다. 확장 권한은 Claude 사용량 페이지 접근, 브라우저 로컬 설정, 주기 알람, 이 기기의 앱 접근에 사용됩니다.

앱은 `127.0.0.1:43127`에서만 수신하고 임의로 생성한 연결 키를 요구합니다. 사용량과 연결 키는 Electron의 사용자 데이터 폴더(Windows의 `%APPDATA%/agentusagev2`)에 저장합니다. 연결 키는 다른 사람과 공유하지 마세요. 다른 프로그램이 이 포트를 사용하면 앱 연결 설정에 오류가 표시됩니다.

## 검증 및 설치 파일 빌드

```powershell
npm test
npx playwright install chromium
npm run test:ui
npm run dist:win
```

`release`에 NSIS 설치 파일과 Windows 실행용 ZIP이 만들어집니다. Linux에서는 `npm run dist:win:zip`으로 실행용 ZIP만 빌드할 수 있습니다. 저장소를 GitHub에 올리면 Windows 워크플로가 테스트 후 설치 파일·실행용 ZIP·브라우저 확장 ZIP을 아티팩트로 제공합니다. 현재 실행 파일과 설치 파일에는 코드 서명이 설정되어 있지 않습니다.

## Linux 클라우드 개발

이 클라우드에서는 웹 화면, 파서, 로컬 HTTP 통신을 검증할 수 있습니다. 네이티브 트레이·작업표시줄 배치·자동 시작·설치 파일의 실제 동작은 Windows에서 별도로 확인해야 합니다.

```bash
npm ci
npm run dev:web
npm run build
npm test
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:ui
```

`dev:web`은 화면만 실행하며 트레이·연결 키·자동 시작을 제공하지 않습니다. 프록시가 필요한 Node.js 24 환경에서는 설치 시 `NODE_USE_ENV_PROXY=1`을 사용할 수 있습니다. 네이티브 Linux 실행에는 GUI 디스플레이와 정상적인 Electron 샌드박스 설정이 필요합니다.

## 구성

- `electron/`: 위젯 창, 작업표시줄·트레이, 세션 암호화 저장·직접 조회, 연결 키 인증 HTTP 수신
- `src/`: 3줄 위젯과 상세 사용량·연결 설정 화면
- `extension/`: Chrome·Edge Manifest V3 확장, 사용량 화면 파서
- `tests/`: 파서·통신 검증과 Playwright UI 테스트
- `.github/workflows/windows.yml`: Windows 테스트와 설치 파일 빌드
